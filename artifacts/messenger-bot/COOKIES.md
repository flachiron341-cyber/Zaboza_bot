# كوكيز zaboza bot بأمان

## الخيار اليدوي: appstate.json

ضع مصفوفة appstate التي تريد استخدامها في الملف:

```text
appstate.json
```

هذا هو المصدر الأساسي. لتغيير حساب البوت، استبدل محتوى الملف بتصدير الحساب
الجديد ثم أعد تشغيل workflow. البوت لا يكتب فوق الملف أثناء التشغيل.

## الخيار الاحتياطي: سر Replit

يمكن أيضاً وضع نفس التصدير في سر Replit باسم `FACEBOOK_APPSTATE`. يستخدمه
البوت فقط عندما يكون `appstate.json` فارغاً أو غير صالح، ولا يطبع قيمته أو
يحفظ نسخة منه في الملفات.

## الاستخدام

1. صدّر كوكيز فيسبوك من المتصفح بصيغة JSON، أو انسخ Cookie header النصي.
2. ضع التصدير في الملف:

```text
cookies.txt
```

3. شغّل الأمر من مجلد البوت:

```bash
pnpm run fix-cookies
```

أو مرّر مسار ملف التصدير:

```bash
pnpm run fix-cookies -- /path/to/cookies-export.json
```

سيحوّل المثبت الصيغة إلى:

```text
appstate.json
```

إذا استخدمت `cookies.txt` ثم شغّلت المثبت، فسيتم تحديث `appstate.json`. البوت
لا يكتب فوقه أثناء التشغيل.

## ملاحظات مهمة

- يجب أن تحتوي الكوكيز على `c_user` و`xs`.
- المثبت يصلح الصيغة والتكرارات فقط؛ لا يستطيع جعل كوكيز منتهية أو ملغاة تعمل.
- بعد تثبيت كوكيز جديدة، أعد تشغيل workflow الخاص بالبوت.
- لا تضع كوكيز الحساب داخل رسائل المحادثة أو ملفات عامة. استخدم الملف المحلي
  فقط داخل Replit الخاص بك، أو استخدم سر `FACEBOOK_APPSTATE`.
