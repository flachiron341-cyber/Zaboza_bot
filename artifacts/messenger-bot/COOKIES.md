# كوكيز zaboza bot بأمان

## الخيار المفضل: سر Replit

ضع تصدير الكوكيز في سر Replit باسم:

```text
FACEBOOK_APPSTATE
```

يمكن إدخال مصفوفة appstate بصيغة JSON أو Cookie header نصياً. البوت يقرأ السر
أولاً ولا يطبع قيمته أو يحفظ نسخة منه في الملفات.

## الاستخدام

1. صدّر كوكيز فيسبوك من المتصفح بصيغة JSON، أو انسخ Cookie header النصي.
2. ضع التصدير في الملف:

```text
cookies.txt
```

3. شغّل الأمر من مجلد البوت:

```bash
pnpm run fix-cookies
```

أو مرّر مسار ملف التصدير:

```bash
pnpm run fix-cookies -- /path/to/cookies-export.json
```

سيحوّل المثبت الصيغة إلى:

```text
manual-appstate.json
```

وهذا هو الملف الاحتياطي الذي يقرأه البوت عند غياب السر. البوت لا يكتب فوقه
أثناء التشغيل.

## ملاحظات مهمة

- يجب أن تحتوي الكوكيز على `c_user` و`xs`.
- المثبت يصلح الصيغة والتكرارات فقط؛ لا يستطيع جعل كوكيز منتهية أو ملغاة تعمل.
- بعد تثبيت كوكيز جديدة، أعد تشغيل workflow الخاص بالبوت.
- لا تضع كوكيز الحساب داخل رسائل المحادثة أو ملفات عامة. استخدم سر
  `FACEBOOK_APPSTATE` متى أمكن.
